# 09 — Tools & Budget

_Assumption: ~$1,200/month working budget. A lean founder-led stack costs far less than that — so the plan is
a cheap **core** plus optional **data + a small ad test** to spend the rest productively. (If "$1,200" was a
one-time total, drop the ad test and treat Sales Navigator as the one splurge — see note at bottom.)_

## Core stack (the must-haves) — ~$300–400/mo
| Need | Tool (examples) | ~Cost/mo | Notes |
|---|---|---|---|
| Find the human / signer | **LinkedIn Sales Navigator Core** | ~$99 (1 seat) | The single highest-leverage buy; share one seat to start |
| Sending domain + inboxes | **Google Workspace** on a separate domain (e.g. getveristasis.com) | ~$14 (2 seats) + ~$12/yr domain | NOT your primary domain; set SPF/DKIM/DMARC |
| Cold-email sending + warmup | **Smartlead** or **Instantly** | ~$37–97 | Built-in warmup + sequencing + deliverability |
| Email verification | **NeverBounce / ZeroBounce** (pay-as-you-go) | ~$10–25 | Verify before sending; protect deliverability |
| Prospect data / enrichment | **Apollo.io** (Basic) | ~$49–99 | Emails + filters; cross-check with SAM/USAspending |
| CRM / pipeline | **HubSpot Free** or a Google Sheet (08 columns) | $0 | Don't overspend here early; a sheet is fine |
| Scheduling | **Cal.com** (free) or Calendly | $0–12 | The `[calendar link]` in every sequence |

**Core subtotal ≈ $310–460/mo.**

## Spend the rest productively — ~$700–850/mo remaining
| Use | What | ~Cost/mo | Why |
|---|---|---|---|
| More data credits | Apollo higher tier / extra export credits / a list-building VA gig | ~$100–300 | Volume of *qualified* contacts is the constraint; buy more good rows |
| Small LinkedIn ad test | Sponsored content / message to the ICP filter (01) for the lead magnet | ~$300–500 | Test whether paid amplifies the launch + waitlist; kill if CPL is bad |
| Design/asset polish | Lead-magnet PDF design (Canva Pro / one-off freelancer) | ~$13–150 | The checklist is a trust asset; make it look credible |
| Buffer | Overages, extra data credits, or a freelance list-builder if Ben needs volume help | remainder | Keep ~$100 flexible |

**Total ≈ $1,100–1,200/mo.**

## Priority order if money gets tight (cut from the bottom)
1. Keep: Sales Navigator, sending domain + Workspace, warmup/sending tool, email verification. _(Without
   these, outbound either doesn't reach inboxes or burns your domain.)_
2. Then: prospect data (you can hand-build lists from SAM/USAspending/LinkedIn for free, just slower).
3. Then: CRM (a spreadsheet is genuinely fine for 300 accounts).
4. Cut first: the paid ad test and design polish. Outbound + a credible free checklist work without them.

## Deliverability setup checklist (Week-0 — do before volume)
- [ ] Buy a **separate sending domain**; don't send cold from veristasis.com.
- [ ] Stand up 1–2 Google Workspace inboxes on it.
- [ ] Configure **SPF, DKIM, DMARC**.
- [ ] Start **warmup** (~2 weeks) before ramping volume; send low-volume by hand meanwhile.
- [ ] Verify every address before sending; keep a **suppression list**; honor opt-outs (CAN-SPAM).
- [ ] Add a footer with a real physical mailing address + opt-out line.

## Note on budget interpretation
This assumes **~$1,200/month**. If you meant ~$1,200 **total** for the launch: keep the **Core stack**
(~$350/mo), skip the ad test, hand-build lists to save data costs, and treat Sales Navigator as the one
non-negotiable paid tool. Flag which it is so the spend plan and the targets in [08](08-metrics-and-tracking.md)
stay realistic.
