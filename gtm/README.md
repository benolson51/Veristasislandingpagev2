# VeriStasis — Go-To-Market (30-day launch)

The complete sales strategy + dated launch plan for VeriStasis, the done-for-you CMMC Level 2 documentation
engine. Built **2026-06-16**. Motion: **direct founder-led outbound** (primary) + **RPO/channel seeding**
(secondary). Every customer-facing line obeys the §12 claims guardrail in the product breakdown.

## How to use this
1. Read **[00-strategy-overview.md](00-strategy-overview.md)** first (the thesis, the why-now, the funnel math).
2. Open **[07-30-day-plan.md](07-30-day-plan.md)** every morning; for this week, work
   **[10-week1-hour-by-hour.md](10-week1-hour-by-hour.md)** hour by hour.
3. Pull send-ready copy from **[03-outbound-playbook.md](03-outbound-playbook.md)** and run demos with
   **[04-demo-and-sales-process.md](04-demo-and-sales-process.md)**.
4. Track everything against **[08-metrics-and-tracking.md](08-metrics-and-tracking.md)** (paste the column
   headers into a sheet). Review every Friday.
5. Keep all copy honest — re-check against §12 before anything goes out.

## Standing reminders
- **Honesty is the product.** Never claim CUI hosting, system connection, FedRAMP, enforced MFA, "AI", or
  any invented proof. The only "we can't read it" claim is about uploaded evidence files. See §12.
- **Capacity is the real cap.** Demos scale; founder-reviewed onboarding doesn't (~3–5/week). Waitlist
  rather than overpromise turnaround.
- **Distribution is the bet.** Direct sells now and validates the message; the RPO channel is the scale lever
  — seed it this month, decide month-2 weighting from real numbers.
- **Dates can slip.** Re-verify the CMMC Phase-2 date before putting it in print.
