## 3. Payment / invoicing — set up BEFORE Day 1 (human task)
Pick one and have it live so a "yes" converts to cash without delay:
- **Stripe Invoicing** — fastest: email a hosted invoice, card or ACH, auto-receipts; supports the monthly
  recurring too. Good default.
- **Accounting tool ACH** (QuickBooks/Wave/Xero) — if you already run books there.
- **Bank ACH / check** — works, but slower; have wire/ACH details ready as a fallback.
> Do this yourself — I won't set up payment accounts or enter financial details. Just confirm an invoice can
> go out the moment a deal signs.

## 4. E-signature + scheduling (cheap, removes friction)
- E-sign: Documenso (open-source) / Dropbox Sign / DocuSign free tier — so the order form signs on mobile.
- Scheduling: the same calendar link from your sequences (Cal.com free / Calendly) for demo + kickoff.

## 5. Onboarding handoff — Ben → Brian (run at signature)
```
HANDOFF — [Company]   Signed: [date]   Tier: [ ]   Delivery target: [date Brian confirmed]
Signer + point of contact (name, email, phone):

Trigger/deadline:                         Anything promised in the sale (must honor):
Payment status: [invoice sent / paid]     Kickoff scheduled: [date/time]

```
Rule: **Brian confirms the delivery date before Ben puts it in the quote.** Never promise a turnaround that
exceeds review capacity (~3–5 intakes/week) — protecting delivery protects the affirmation and the brand.
