## How to scale this to a true ranked 100 (the legitimate way — no scraping)
1. **Gov data (the intent edge):**
   - **SAM.gov** → Entity search, NAICS **332710 / 332721 / 336411 / 541330**, state **CA** → active registrants.
   - **USAspending.gov** → Awards, agency **DoD**, recipient size **small business**, those NAICS, recent FY,
     state CA → companies with *real DoD awards* (confirmed flow-down risk). Export to CSV.
   - **SBIR.gov** → DoD awardees, CA → small innovators newly facing CUI.
2. **Clay** (already set up): import the gov CSV → enrich to find the **owner/CEO/President** + verified email.
3. **Sales Navigator** (in-app, not scraped): confirm the signer per company.
4. **Rank** with the closeability model above; keep the top 100; output in this table format.
